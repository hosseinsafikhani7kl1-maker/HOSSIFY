# HOSSIFY — سایت کاتالوگ اپلیکیشن‌ها

نسخهٔ جدید، کم‌حجم و تک‌صفحه‌ای برای همان GitHub Pages فعلی است. هفت برنامهٔ موجود در سایت قبلی، همراه با اطلاعات دوزبانه و لینک‌های مایکت، در کاتالوگ اولیه قرار دارند و از طریق HOSSIFY Site Manager قابل ویرایش هستند.

## ساختار

```text
index.html       پوستهٔ سایت
style.css        طراحی واکنش‌گرا و شیک
app.js           ناوبری، زبان، کارت‌ها و پنجرهٔ جزئیات
script.js        آرایهٔ برنامه‌ها؛ توسط HOSSIFY Site Manager دریافت و به‌روزرسانی می‌شود
analytics-config.js  آدرس اختیاری Cloudflare Worker برای شمارش بازدید و کلیک دانلود
assets/          آیکون و تصاویر فعلی اپ‌ها
```

## جایگزینی در مخزن GitHub

1. از مخزن HOSSIFY فعلی یک Backup یا Commit تهیه کنید.
2. همهٔ فایل‌ها و پوشهٔ `assets` این پروژه را در **ریشهٔ همان مخزن** کپی کنید.
3. `index.html`، `style.css`، `app.js`، `script.js` و `assets/` باید در شاخهٔ `main` قرار بگیرند.
4. پس از Push، GitHub Pages همان آدرس فعلی را با طراحی تازه نشان می‌دهد.

برای ویرایش برنامه‌ها، اپ **HOSSIFY Site Manager** را نصب کنید و در آن «دریافت از GitHub» را بزنید؛ پس از Preview و تأیید، انتشار آرایهٔ `apps` در همان `script.js` را به‌روزرسانی می‌کند و سایت دادهٔ تازه را می‌خواند.

### پیش‌نمایش و وضعیت انتشار

- برای دیدن پیش‌نمایش یک محصول بدون نمایش آن در فهرست عمومی، فیلد اختیاری `status: "draft"` را به شیء آن در آرایهٔ `apps` اضافه کنید. سپس سایت را با شناسهٔ محصول باز کنید: `https://hosseinsafikhani7kl1-maker.github.io/HOSSIFY/?preview=8`.
- در حالت پیش‌نمایش فقط همان محصول دیده می‌شود و برچسب «پیش‌نمایش» و پیام منتشرنشده دارد؛ دکمهٔ دانلودی نشان داده نمی‌شود. پس از تأیید، وضعیت را به `"coming-soon"` تغییر دهید تا در کاتالوگ عمومی با برچسب «به‌زودی» دیده شود. برای محصول آمادهٔ دریافت، وضعیت را حذف کنید و لینک مایکت را وارد کنید.
- اگر محصولی لینک مایکت و دانلود مستقیم نداشته باشد، سایت به‌طور خودکار «به‌زودی» نشان می‌دهد؛ لینک دانلود ساختگی تولید نمی‌شود.
- GitHub Pages سایت ایستا و عمومی است: اطلاعات محصول `draft` نیز در فایل `script.js` قابل مشاهده است. از این وضعیت برای مخفی‌کردن اطلاعات محرمانه استفاده نکنید.

## دانلود و آمار

- در حال حاضر برنامه‌های منتشرشده از لینک مایکت استفاده می‌کنند. لینک یا میزبانی APK مستقیم را بعداً، پس از آماده‌شدن فایل‌ها، جداگانه تنظیم کنید.
- بعد از راه‌اندازی Worker، آدرس آن را در `analytics-config.js` در مقدار `endpoint` بگذارید. Worker فقط «بازدید» و «کلیک دانلود» را ثبت می‌کند؛ نصب موفق روی گوشی قابل تشخیص نیست.
