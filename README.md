# HOSSIFY — سایت کاتالوگ اپلیکیشن‌ها

نسخهٔ جدید، کم‌حجم و تک‌صفحه‌ای برای همان GitHub Pages فعلی است. کاتالوگ در ابتدا خالی است و فقط پس از انتشار برنامه‌ها از طریق HOSSIFY Site Manager نمایش داده می‌شود.

## ساختار

```text
index.html       پوستهٔ سایت
style.css        طراحی واکنش‌گرا و شیک
app.js           ناوبری، زبان، کارت‌ها و پنجرهٔ جزئیات
script.js        آرایهٔ خالی اپ‌ها؛ توسط HOSSIFY Site Manager به‌روزرسانی می‌شود
analytics-config.js  آدرس اختیاری Cloudflare Worker برای شمارش بازدید و کلیک دانلود
assets/          آیکون و تصاویر فعلی اپ‌ها
```

## جایگزینی در مخزن GitHub

1. از مخزن HOSSIFY فعلی یک Backup یا Commit تهیه کنید.
2. همهٔ فایل‌ها و پوشهٔ `assets` این پروژه را در **ریشهٔ همان مخزن** کپی کنید.
3. `index.html`، `style.css`، `app.js`، `script.js` و `assets/` باید در شاخهٔ `main` قرار بگیرند.
4. پس از Push، GitHub Pages همان آدرس فعلی را با طراحی تازه نشان می‌دهد.

پس از این مرحله، اپ **HOSSIFY Site Manager** برای دریافت و ویرایش همان `script.js` استفاده می‌شود. در آن اپ، ابتدا «دریافت از GitHub» را بزنید؛ پس از Preview و تأیید، انتشار فقط آرایهٔ `apps` را تغییر می‌دهد و سایت جدید فوراً دادهٔ تازه را می‌خواند.

## دانلود مستقیم و آمار

- در پنل مدیر، برای برنامه‌ای که در مایکت منتشر نشده، فیلد «لینک دانلود مستقیم» را با مسیر فایل در همان مخزن پر کنید؛ نمونه: `downloads/my-app.apk`.
- تا قبل از اتصال Cloudflare، دکمهٔ دانلود مستقیم کار می‌کند ولی آمار ثبت نمی‌شود.
- بعد از راه‌اندازی Worker، آدرس آن را در `analytics-config.js` در مقدار `endpoint` بگذارید. Worker فقط «بازدید» و «کلیک دانلود» را ثبت می‌کند؛ نصب موفق روی گوشی قابل تشخیص نیست.
